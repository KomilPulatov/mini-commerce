# Micro Service Commerce — Laravel Microservices Learning Project

This repository is intentionally small. The goal is to evolve one system from a simple Laravel service into a small distributed system without unnecessary business complexity.

## Build order

1. User Service
2. Refactor with Container / DI / Providers / Services / Repository
3. Product Service
4. Service-to-service HTTP
5. Order Service
6. Payment Service
7. Events + messaging
8. Notification Service
9. Queues + reliability
10. API Gateway
11. Docker Compose
12. Observability
13. Failure scenarios

See `/docs` for the detailed specifications.
